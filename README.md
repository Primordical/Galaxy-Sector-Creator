# Galaxy Sector Generator
Generate your own galaxy of solar systems!

What this python script does is:
+ Create *pseudo-realistic* solar systems with __planets, moons, and stars__.
+ Generate __procedural planetary names__, __realistic radiuses, colors, and subtypes__ , and __a detailed hierarchy of orbital parents.__

## How does it work?
This extension uses __random prefix-suffix-root name generators__ for multi-syllable names, __realistic radius ranges for types of planets__, as well as subtypes __based on radius, and colors.__
## How do I edit the output?
If you check the code, at the end there are the __generation functions__. There are many customizable options, like *amount of systems, types, output in terminal or file, file location, realism,* and __much more!!__
